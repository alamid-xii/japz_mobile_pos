# JAPZ ERP inventory diagrams

Approved title: JAPZ ERP: JAPZ Grill Burger & Bistro Restaurant Inventory System

The Word document contains all 17 diagrams in the activity-table order, with short descriptions, implementation notes and source references. The visual direction follows approved Option B and the supplied style reference, with standard notation retained for formal diagrams.

- `JAPZ-Inventory-17-Diagrams.docx`: assembled document.
- `svg/`: 17 scalable vector exports.
- `png/`: 17 exports at twice their design dimensions.
- `editable/`: 17 individual draw.io files and one combined file with 17 diagram tabs.
- `assets/` and `ASSET-SOURCES.json`: original technology/Lucide SVGs and source/hash records.

Open a `.drawio` file in diagrams.net to edit its separate shapes, text and connectors. SVGs can also be edited in vector software. The Word document embeds PNGs; edit the diagram source and replace the corresponding picture when changing diagram content.

Examples and gaps are labeled in the document. Object values and request durations are illustrative. The UML profile is a documentation convention. Deployment shows local source configuration. Prepared stock belongs to the shared MenuItem model; recipe components are JSON values, not an invented table. Reports execute in inventory route handlers. No application code or business records were changed for this deliverable.

Diagram exports were rendered and visually inspected. The DOCX was rendered using Microsoft Word and its page images inspected. The LibreOffice-based skill renderer could not run because LibreOffice is unavailable; the native Word render provided the visual review instead. Source inspection does not claim a fresh application test run, production deployment or measured timing.
