# JAPZ Inventory Architecture Options

Open **JAPZ-Architecture-Options.docx** to review the two layouts, one per page.

- **Option A:** three horizontal layers and grouped backend responsibilities.
- **Option B:** a left-to-right composition with the guarded API, peer handler/service groups and shared persistence.

Both use the supplied visual reference: light borders, charcoal icon badges, restrained gold layer labels and small connection ports. Technology marks retain their original artwork and colors. MySQL is identified with a Lucide database symbol and its name.

The `svg` and `png` folders contain matching individual exports. Open `editable/JAPZ-Architecture-Two-Options.drawio` in diagrams.net for both editable pages, or open an individual draw.io file. Labels, shapes, connectors and asset positions remain editable; logos/icons are embedded so the files work without external image links.

`ASSET-SOURCES.json` records the original asset locations and SHA-256 hashes. These are review options for Diagram 01, **System Architecture Diagram**. The remaining 16 diagrams await approval of a visual direction.
